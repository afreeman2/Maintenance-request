# تثبيت تطبيق طلبات الصيانة

شغّل `output/MaintenanceRequestSetup/Setup.exe` على Windows ‏64 بت. يحتوي المثبّت على التطبيق وملفات .NET Desktop وDevExpress وSQL Client، ويعمل دون إنترنت.

1. أدخل اسم خادم SQL واسم مستخدم SQL وكلمة مروره. يحتاج المثبّت إلى الاتصال بقاعدة `Maintenance_Dabase` المشتركة مع منظومة الخدمات والصيانة.
2. اضغط **تثبيت التطبيق**، ثم **فتح المنظومة**. يظهر اختصار **منظومة طلبات الصيانة** على سطح المكتب وفي قائمة ابدأ، ويُحفظ اعتماد SQL مشفّرًا لحساب Windows المثبّت.
3. سجّل دخول التطبيق بحساب طلبات الصيانة. يستخدم المثبّت قاعدة العمل المهيأة، والترحيل من اختصاص مثبّت منظومة الخدمات والصيانة.

ملف التشغيل `تطبيق طلبات الصيانة.exe` داخل `%LOCALAPPDATA%\SSF\MaintenanceRequest\Application`. لإعادة بناء الحزمة شغّل `packaging/Build-OfflineSetup.ps1` مع توفر المشروع الشقيق وحزم البناء.
